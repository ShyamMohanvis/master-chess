# Chess Master

A premium, fully featured web-based chess game built with Vite, TypeScript, and modern CSS featuring a photorealistic wooden aesthetic, smooth animations, and a powerful WebWorker-based AI.

## Live Demo
[Play Chess Master Here](https://ShyamMohanvis.github.io/chess-master/)

## Features
- **Premium UI**: Photorealistic dark wood textures, glassmorphism UI components, and gold accents.
- **Multiple Game Modes**: Play against an AI or challenge a friend in 2-Player Local mode.
- **Adjustable AI Difficulty**: Choose between Easy, Medium, and Hard AI modes.
- **Smooth Animations**: Pieces glide naturally across the board with CSS transitions.
- **Responsive Design**: Play on desktop or mobile with a layout that adapts to your screen size.
- **Move History & Undo**: Easily review past moves and undo mistakes.
- **Legal Move Validation**: Full enforcement of chess rules, including castling, en passant, and promotion.

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/ShyamMohanvis/chess-master.git
   ```
2. Navigate to the project directory:
   ```bash
   cd chess-master
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used
- HTML5 & Modern CSS3
- TypeScript
- Vite
- Web Workers (for non-blocking AI computation)
